# What Are Cursor Skills

Cursor Skills are standardized instruction packages that teach an AI agent how to execute a specific kind of task. A skill typically encodes trigger context, execution steps, expected output structure, and task-specific constraints.

Core outcomes:
- Reusability: repeated workflows become a reusable capability.
- Consistency: teams can apply common implementation patterns.
- Transferability: the same skill can be used in multiple projects.
- Scalability: complex, multi-step tasks become easier to invoke.

In practice, Skills are best seen as operational playbooks for agent behavior, while the project codebase remains the implementation target.
