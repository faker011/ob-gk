# OpenSkills

OpenSkills is a CLI utility for installing and managing skill repositories. It supports:
- installing from GitHub repositories or local paths;
- selecting individual skills interactively;
- syncing skill metadata into `AGENTS.md`;
- updating previously installed skills.

It is typically the most maintainable path for long-term, multi-skill workflows.
