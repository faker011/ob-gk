# AGENTS.md

`AGENTS.md` is a generated index that lists available installed skills and their descriptions for agent discovery.

Operational role:
- summarizes active skills in a single file;
- helps the agent choose suitable capabilities from context;
- is refreshed by `openskills sync` in CLI-based workflows.

This file should be treated as generated state rather than manually curated truth.
