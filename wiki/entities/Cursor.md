# Cursor

Cursor is the development environment where skills are discovered and executed by AI agents. In this wiki's context, Cursor is both:
- the runtime that loads skill instructions from recognized directories;
- the interactive interface where users request tasks and inspect outputs.

Cursor's skill model benefits from clear skill metadata and consistent directory structure.
