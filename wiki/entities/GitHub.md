# GitHub

GitHub is the primary distribution channel for shared skill repositories and remote imports.

In skill workflows, GitHub is used for:
- hosting public skill packs;
- version pinning via branch/tag references;
- remote installation through CLI or UI;
- private repository access via token-based authentication.

Network reachability to GitHub directly impacts remote install success.
